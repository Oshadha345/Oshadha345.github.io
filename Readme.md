# Oshadha Samarakoon — Portfolio

## Updating the public CV

The CV download buttons on the site use this stable public file:

`public/cv/oshadha-samarakoon-cv.pdf`

To update the CV later, replace that PDF with the new version while keeping the same filename. Then run:

```powershell
npm run build
```

The build copies it to `docs/cv/oshadha-samarakoon-cv.pdf`, which is the file served by GitHub Pages. No source-code or link changes are needed when the filename remains unchanged.

The current source copy supplied for this version is:

`new_items/CV/CV.pdf`
